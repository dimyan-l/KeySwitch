# Dictionary attribution

`Resources/Dictionaries/es.tsv` is a filtered and rescored derivative of `content/2018/es/es_50k.txt` from [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords/blob/525f9b560de45753a5ea01069454e72e9aa541c6/content/2018/es/es_50k.txt), based on OpenSubtitles 2018. Original content and this derivative: [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). Changes: removed non-word tokens, normalized Unicode to NFC, retained Spanish alphabetic words, and converted raw counts to log-frequency scores.

`Resources/Dictionaries/en.tsv` and `custom_en.txt` were copied from KeySwitch RU/EN. That project's README credits [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018, CC BY-SA 4.0) and [IlyaSemenov/wikipedia-word-frequency](https://github.com/IlyaSemenov/wikipedia-word-frequency). The English TSV is a merged and transformed word-frequency list.
