# KeySwitch: умный переключатель раскладки RU/EN для macOS

> **0.3.4 RC — альтернативная локальная ветка.** Не включает все возможности GitHub v0.3.2: раннее переключение, iCloud, контекст предложения и прежний интерфейс не перенесены. [Сравнение и ограничения](Design/UPSTREAM_INTEGRATION.md). На чистой установке опечатки и запись истории буфера выключены; включаются в настройках. При активной iCloud-настройке старой версии данные блокируются до явного переноса, а не перезаписываются.

Личный аналог Punto/Caramba. Живёт в строке меню и показывает текущую раскладку (`RU` / `EN`). Если слово набрано не в той раскладке, после пробела или Enter оно само перепечатывается правильно, и раскладка переключается. Знак препинания на клавише, которая в другой раскладке означает букву, проверяется после следующего разделителя.

## Что умеет

| Действие | Как |
|---|---|
| Автоисправление слова (`ghbdtn` → `привет`, `руддщ` → `hello`, `ыйд` → `sql`) | само, на границе слова |
| Исправление явных опечаток (`превет` → `привет`, `recieve` → `receive`) | само, на границе слова; включается в Настройки → Исправления |
| Короткое слово перед исправленным тоже исправляется (`z ghbdtn` → `я привет`) | само |
| Отменить автоисправление (слово запоминается и больше не трогается) | **правый ⌥** сразу после исправления |
| Исправить слово, которое не распозналось (тоже запоминается) | **правый ⌥** в середине слова или сразу после него |
| Сменить раскладку выделенного текста | **⌃⌥R** |
| Исправить уже написанное слово или изменить его регистр | выделить одно слово мышью или Shift+стрелка и выбрать вариант во всплывающей панели |
| Исправить слово у курсора после того, как продолжили писать | поставить курсор внутри слова или сразу у его края и нажать **правый ⌥**; при нескольких вариантах выбрать нужный |
| История буфера обмена (после включения: последние 30 текстов + закреплённые фразы) | **⌃⌥V**: клик или цифра 1–9 вставляет, ⌥+клик закрепляет |
| Свои слова (имена, компании, жаргон) | Настройки → Словари → «Мои слова» или «Мои файлы словарей» |
| Исключения для раскладки, опечаток или всех исправлений | Настройки → Словари → «Исключения» |
| Отключить в конкретном приложении | меню → «Не исправлять в …» |

В терминалах, IDE и менеджерах паролей исправление выключено по умолчанию. В полях паролей macOS сама не показывает клавиши сторонним программам.
Панель вариантов появляется только для одного выделенного слова и не меняет текст до нажатия на вариант. Её можно отключить в Настройки → Исправления → «Варианты при выделении слова».

**Осторожный режим** включён по умолчанию: статистически сомнительные варианты подсвечиваются оранжевым на плашке и исправляются только по правому ⌥. Слова с цифрами, адреса, идентификаторы с `_` и составные имена с точкой не меняются автоматически. Tab не запускает исправление, чтобы отмена не затронула следующее поле. Автоматическая перепечатка ограничена 24 символами.

## Как оно думает

1. **Словари.** 80 тыс. самых частых слов на каждый язык. Источники: субтитры (разговорная речь) и Википедия (термины). Плюс свой IT- и sales-жаргон: `созвон`, `деплой`, `аутстафф`, `фидбек`, SQL, DBA, DWH, HubSpot, LinkedIn и так далее.
2. **Сравнение двух прочтений.** Программа хранит не буквы, а нажатые клавиши. Поэтому одни и те же нажатия можно прочитать в обеих раскладках и выбрать прочтение, которое больше похоже на настоящее слово. Если оба прочтения настоящие слова (`he` / `ру`, `here` / `руку`), ничего не меняется, пока одно не окажется во много раз частотнее другого.
3. **Буквенная модель (триграммы)** для слов, которых нет в словаре: насколько сочетания букв похожи на русские или английские.
4. **Обучение на ваших действиях.** Отмена создаёт исключение для того вида исправления, который вы отменили. Ручное исправление добавляет распознанное слово в личный словарь.
5. **Опечатки.** Только если менять раскладку не нужно, программа ищет однозначное исправление в локальном словаре. Проверка ограничена 16 буквами и не обращается к сети. Return/Enter и Tab не запускают автоматическую орфографическую подстановку, чтобы не отправить непроверенную замену.

Замеры на словарях (`tools/classifier.py`):

| | Ложные срабатывания | Исправлено при неверной раскладке |
|---|---|---|
| Частые русские слова | 0,00% | 99,6% |
| Частые английские слова | ~0,03% | 92–93% |
| Редкие слова, которых нет в словаре | 0,1–0,2% | ~92% |

## Установка (один раз, минут 10)

1. Поставьте инструменты разработчика, если их ещё нет (полный Xcode не нужен):
   ```bash
   xcode-select --install
   ```
2. Распакуйте архив, например в `~/Projects/KeySwitch`, и соберите:
   ```bash
   cd ~/Projects/KeySwitch
   ./build_app.sh --install
   ```
   Скрипт скомпилирует программу, проверит словари и положит `KeySwitch.app` в «Программы». Запустите приложение вручную после проверки разрешений. Ошибка самопроверки остановит установку.
3. Выдайте разрешения в «Системные настройки → Конфиденциальность и безопасность»:
   - **Универсальный доступ** → включить KeySwitch;
   - **Мониторинг ввода** → включить KeySwitch.

   Проверьте состояние и разрешения в Настройки → Исправления. Значок 🔒 и пояснение в меню означают, что macOS включила защищённый ввод; KeySwitch не отключает эту защиту.

   Проверить разрешения именно у установленной копии, не запуская перехват клавиш:
   ```bash
   /Applications/KeySwitch.app/Contents/MacOS/KeySwitch --diagnose-permissions
   ```
   Если оба разрешения выданы, а перехват всё равно не запускается, повторное переключение «Универсального доступа» не поможет: проверьте сообщение в меню KeySwitch. Не запускайте одновременно копии из `/Applications` и папки `build`.
4. **Выключите Punto Switcher / Caramba**, если они стоят. Две программы будут драться за одни и те же слова.
5. Меню → «Запускать при входе в систему».

### Чтобы разрешения не слетали после каждой пересборки

С временной ad-hoc подписью macOS может считать пересобранную программу новой и заново спрашивать доступ. Для обновлений без повторной выдачи прав нужна стабильная подпись одним и тем же сертификатом. Скрипт принимает имя действующего сертификата через `KEYSWITCH_CODESIGN_IDENTITY`; также ищет локальные сертификаты `KeySwitch RU Local Signing 2026` и `KeySwitch Dev`. Без сертификата `./build_app.sh` создаст тестовую сборку, а `--install` остановится до замены приложения. Если в «Программах» лежит `KeySwitch 2.app`, установка также остановится: сначала закройте приложение и разберитесь с дубликатом, чтобы не получить две копии с одинаковыми разрешениями. Локальный сертификат подходит для этого Mac, но не заменяет Apple Developer ID при распространении приложения.

`--diagnose-data` показывает количество выученных слов и действующих правил без запуска перехвата. В приложение входят 13 русских и 2 английских стартовых правила. Личные имена и адресоподобные исключения исключены из публикуемых ресурсов; существующий пользовательский `learned.json` не очищается. Удалённые в настройках правила не восстанавливаются при следующем запуске.

## Структура

```
Sources/KeySwitch/
  SwitchEngine.swift      перехват клавиш, буфер слова, автоисправление, правый ⌥
  Classifier.swift        словари + триграммы + решение «менять / не менять»
  SpellCorrector.swift    осторожная проверка опечаток по локальному словарю
  Rules.swift             личные исключения для раскладки и опечаток
  KeyboardLayouts.swift   реальные раскладки macOS (Русская, Русская–ПК, ABC, US)
  Typer.swift             печать исправлений (Unicode-события, не зависят от раскладки)
  MotionBadge.swift       анимированная плашка EN/RU в строке меню
  ClipboardHistory.swift  история буфера и закреплённые фразы
  AppDelegate.swift       меню, горячие клавиши, настройки
Resources/Dictionaries/   ru.tsv, en.tsv, custom_ru.txt, custom_en.txt
tools/                    Python-прототип классификатора и сборщик словарей
```

Личные данные лежат в `~/Library/Application Support/KeySwitch/`: выученные слова, исключения, закреплённые фразы, `my_*.txt`. История буфера живёт только в памяти, на диск не пишется. Сетевых запросов приложение не делает.

## Плашка в строке меню

Компактный индикатор `EN | RU` использует системный цвет акцента и переход за 160 мс. После исправления появляется короткий отклик; символ Ⅱ обозначает паузу. При включённом параметре macOS «Уменьшение движения» анимации отключены.

## Известные ограничения

- Решение принимается в конце слова, а не на лету: первые 2–3 буквы почти всегда неоднозначны.
- Если щёлкнуть мышью в середину слова и допечатать, программа видит только допечатанную часть.
- Горячие клавиши пока зашиты в коде (`Hotkey` в `SwitchEngine.swift`, правый ⌥ — код клавиши 61).
- Перехват клавиш можно приостановить из меню. Если macOS отключила его из-за таймаута, приложение оставляет ввод свободным и ждёт ручного возобновления. Для отключения автозапуска без запуска перехватчика: `KeySwitch.app/Contents/MacOS/KeySwitch --disable-login`.

Источники словарей: [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018, CC-BY-SA 4.0), [IlyaSemenov/wikipedia-word-frequency](https://github.com/IlyaSemenov/wikipedia-word-frequency).

### Настройки и внешний вид

«Настройки…» в меню KeySwitch открывают отдельное окно: исправления и доступ macOS, словари, приложения и клавиши. В словарях доступны поиск, добавление слов и исключений, удаление и отмена последнего изменения. Последние 50 замен хранятся только в памяти до выхода.

Панель у слова управляется стрелками ↑/↓ или ←/→, Enter применяет выбранный вариант, Esc закрывает панель. Индикатор EN/RU стал компактнее; символ Ⅱ обозначает паузу. История буфера доступна в коротком меню и по ⌃⌥V.
