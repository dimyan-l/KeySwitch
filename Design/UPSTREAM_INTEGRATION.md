# Интеграция улучшений GitHub

Исходная версия GitHub: `dimyan-l/KeySwitch`, commit `e27b88b3eeb4a2f426ca17db1866022fa67e5d3d` (v0.3.2).

Локальная версия имеет другую архитектуру, macOS 13+ и вложенный EN/ES вариант. Релиз GitHub рассчитан на macOS 27 и содержит собственные интерфейс, движок и пользовательские сценарии. Это не автоматическая замена одного дерева другим.

## Выбранные переносы

- Защита синтетической перепечатки по идентичности активного процесса перед каждой парой событий: идея upstream Typer адаптирована к локальному механизму отмены и тестовому event sink.
- Индикация Secure Event Input: пользователь видит причину отсутствия исправлений, контекст сбрасывается на переходах, защита macOS не отключается.
- Запрет автоматической орфографической подстановки на Return/Enter (проверка раскладки остаётся): не отправлять непроверенную замену вместе с сообщением.
- Явное управление записью истории буфера; история и опечатки отключены по умолчанию на чистой установке, сохранённые явные настройки не переопределяются.
- Совместимость формата learned.json: различение локальной reference epoch и upstream Unix epoch, сохранение неизвестных полей, блокировка неподдерживаемого iCloud-режима вместо тихой потери слов.

## Сознательно не перенесено

- EngineThread: требует перевести всё состояние движка и его вызовы на один поток; перенос одного файла создаст гонки.
- iCloud и журнал набранных исправлений: меняют хранение/конфиденциальность и требуют отдельной проверки.
- Новый интерфейс macOS 27, mid-word switching, контекстные и регистровые эвристики: не являются частью текущего проверенного набора возможностей.

Локальные подсказки выделенного слова, история буфера с закреплением и осторожные правила остаются. Нельзя утверждать, что все возможности v0.3.2 присутствуют в этой альтернативной ветке.

## Публикация

Подготавливается ветка `release/local-0.3.4-rc.1`, основанная на истории GitHub, с отдельным деревом локальной версии и предварительным тегом `v0.3.4-rc.1`. Стабильный релиз v0.3.2 и его исходники в main сохраняются. CFBundleShortVersionString использует числовую версию 0.3.4, статус предварительного выпуска указан тегом/релизом.

Приложение не нотаризовано Apple; локальная подпись не является Developer ID. Автоматические проверки не заменяют испытания ввода в реальных редакторах. Публикация не обновляет установленную копию в /Applications.
